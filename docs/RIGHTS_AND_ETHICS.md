対象：Dopamirage（`index.html` 一式、ガイド用デモ動画、README）／対応言語：日本語・英語・スペイン語・ポルトガル語・簡体中文
実施日：2026年10月

> この文書は、公開前のセルフチェックの記録です。法的助言ではありません。商用化・大規模公開などの際は、各国の専門家による確認をおすすめします。

## 2. 引用文の著作権 ― 国ごとの基準と採用ルール

引用は「部屋の主たるコンテンツ」として表示されるため、日本の著作権法32条の「引用」（主従関係が必要）には当たりません。したがって **すべての対象国でパブリックドメインであること** を条件にしました。

| 国・地域 | 保護期間（著作者の死後） | 補足 |
|---|---|---|
| 日本 | 70年（2018年12月30日以降） | 1967年以前に亡くなった著者は旧法（50年）で既に消滅。連合国民の著作物には戦時加算（約10年）あり |
| スペイン | 70年。ただし **1987年12月7日より前に亡くなった著者は80年** | 例：サンタヤーナ（スペイン国籍、1952年没）はスペインで2032年まで保護 → 削除 |
| ポルトガル | 70年 | |
| ブラジル | 70年 | |
| 中国 | 50年 | |
| 米国（ホスティング） | 発行年基準：1931年より前に発行された作品はパブリックドメイン | 未発表作品の死後公表には注意（例：ディキンソンの一部の詩は1945年初出 → 米国で保護中） |

**採用ルール**
1. 著者の没年が 1955 年以前（死後70年経過）。スペイン国籍の著者は 1945 年以前。
2. 米国についても、出典作品が 1931 年より前に発行されていること（または古代の文献・伝統的なことわざ）。
3. 出典をたどれる言葉に限る。ネット上の「〜の名言」で出典不明のものは採用しない。
4. 原文が英語以外のものは、近代の翻訳の文言を使わず、原文から独自に訳す（または原文そのものを使う）。

**結果（件数）**

|---|---|---|
| Inkbleed 英語・日本語 | 各244 | 各143 |
| Kizuna 英語 | 469 | 179 |

主な削除理由：
- **保護期間内**：上記の近現代の著者、映画・ミュージカルの台詞（『いつか晴れた日に』1995年版の脚本、『レ・ミゼラブル』ミュージカルの歌詞）、楽曲の歌詞（「There is a crack in everything…」はレナード・コーエン）、小説（「A reader lives a thousand lives…」はジョージ・R・R・マーティン）。
- **誤帰属**：例「We are what we repeatedly do…」（アリストテレスではなくウィル・デュラント、1981年没）、「The mind is everything…」「Peace comes from within…」（ブッダではない）、「It does not matter how slowly you go…」（孔子ではない）、「Be yourself; everyone else is already taken」（ワイルドではない）、「Be the change…」（ガンディーの言葉の言い換え）、「Simplicity is the ultimate sophistication」（ダ・ヴィンチではない）など。
- **出典不明・創作の疑い**：日本人作家（夏目漱石・芥川龍之介・森鴎外・太宰治・沢庵・一休・空海）名義の日本語文で、原文が見当たらず英語の流行句を逆輸入したもの。将棋の棋士名義の言葉（出典確認不可）。
- **翻訳の著作権**（訳し直しで対応）：上の表の近代翻訳由来の英文。リルケの「No feeling is final」（Macy & Barrows 1996年訳）は、ドイツ語原文「Kein Gefühl ist das fernste」から各言語で訳し直しました。
- **倫理的配慮**：女性を揶揄する警句（「Women are meant to be loved, not to be understood」など）は、内容が部屋の趣旨にそぐわないため削除。

日本語版の引用は、原文が日本語・漢文のもの（芭蕉、道元、鴨長明、宮本武蔵、一茶、『老子』『荘子』の書き下し等）はそのまま原文を使っています。

## 3. 言語・国ごとの確認

### 日本語（日本）
- 著作権：上記ルールで確認済み。ガイド・UI 文言は本プロジェクトの独自文。
- **薬機法**：疾病の診断・治療・予防をうたう表現は、未承認の医療機器（プログラム医療機器）とみなされるおそれがあります。「EMDR は臨床的に…効果が示されている」「脳のドパミン基線が回復しやすくなる」等を削除し、「治療ではない」「医療機器ではない」と明記しました。
- **景品表示法**：「最も確かな方法」などの断定的な優位性表現を削除しました。
- **個人情報保護法**：個人情報は取得していません（記録は端末の localStorage のみ）。アクセス解析は匿名集計で、ガイドの「プライバシー」で開示しています。

### 英語（米国・英国ほか）
- 著作権：米国の発行年ルールも満たすよう確認済み。
- **米 FDA**：一般的なウェルネス（リラックス・ストレス対処の補助）の範囲の表現に限定し、疾病に関する表現を削除しました。
- 英国・EU の GDPR は下の「プライバシー」を参照してください。

### スペイン語（スペイン・中南米）
- スペインの「1987年以前に亡くなった著者は死後80年」に注意して確認済み（マチャード1939年没・セルバンテス・グラシアン・テレサは保護期間外）。
- **EU 医療機器規則（MDR）**：医療目的をうたわない表現に変更し、「医療機器ではない」と明記しました。
- **GDPR／ePrivacy**：Google Fonts の外部読み込みは、ドイツの判決（ミュンヘン地裁 2022年1月）で違法とされた例があります → 自社ホスト化しました。localStorage は、利用者が求めた機能（記録・設定）に厳密に必要な保存なので同意は不要と判断しています。

### ポルトガル語（ポルトガル・ブラジル）
- ペソア（1935年没）はポルトガル・EU では保護期間外ですが、『メッセージ』（1934年刊）などは **米国では2030年頃まで保護** されるため削除しました。
- **ブラジル LGPD／ANVISA**：個人データの取得なし。ウェルネスの範囲の表現。
- 注記：現在の訳文は欧州ポルトガル語寄りです（「ecrã」「telemóvel」など）。ブラジルの利用者を主に想定する場合は、ブラジル・ポルトガル語版の追加を検討してください（権利上の問題ではありません）。

### 簡体中文（中国本土・その他の地域）
- 引用は古典の原文（老子・荘子・論語・陶淵明・王維・李白・杜甫・蘇軾ほか）が中心で、すべて保護期間外です。外国語の言葉は独自訳です（鄭振鐸・周作人などの既存の中国語訳をそのまま使っていません）。
- **PIPL**：個人情報の取得なし。Google Fonts は中国本土からはつながらないため、自社ホスト化で表示の問題も解消しました。
- サイトは中国本土外（Vercel）でホストされているため、ICP 届出の対象外です。政治的な内容は含みません。

## 4. その他の倫理面

- **誠実な説明**：Kizuna の言葉が「他の訪問者の投稿ではない」ことを明記しました。利用者が残す言葉は端末にだけ保存され、送信されません。
- **安全**：ガイドの「大切なこと」に、医療機器ではないことと、光の変化に敏感な方（光感受性てんかん等）への注意を追加しました。画面全体の明滅はなく、光の変化はゆっくりしたものです（Hoko の拍に合わせた小さな光は最大 220BPM＝毎秒約3.7回ですが、面積が小さく WCAG の小面積の例外の範囲です）。Hoko の周囲安全の注意は既存のとおりです。
- **不調時の案内**：入口の最下部とガイドに、医師・カウンセラー・相談窓口への案内があります（国を限定しない表現）。
- **寄付導線**：Buy Me a Coffee へのリンクは控えめで、表示条件（7回以上の利用・30日に1回まで）も強制的ではありません。
- **ダークパターンなし**：連続記録の喪失を煽る表現や、通知・アカウントはありません。
- **アクセシビリティ**：視差効果を減らす設定（prefers-reduced-motion）を尊重し、キーボード操作・フォーカス表示に対応しています。

## 6. 残る注意点（人の目での確認をおすすめするもの）

1. **出典の最終確認**：残した引用は、出典をたどれると判断したものです。ただし、すべてを原典と一字一句照合したわけではありません。公開前に、少なくとも頻出の著者については原典との照合をおすすめします。
2. **日本語訳の出所**：既存の日本語訳文（外国語の言葉）は独自訳と判断しましたが、作成者本人による確認が最も確実です。
3. **Vercel Web Analytics**：Cookie を使わない匿名の集計ですが、外部サービスであることに変わりはありません。完全に「計測なし」にしたい場合は、`index.html` の該当スクリプト2行を削除してください。
4. **README の「No tracking」の表現**：上記に合わせて「部屋の中での行動は端末から出ない／匿名のページビューのみ計測」と正確な表現に変更済みです。
5. **スペイン語・ポルトガル語の引用数**：審査の結果 20〜30件台と少なめです。保護期間外で出典の確かな言葉を追加すると、繰り返しが減ります。
